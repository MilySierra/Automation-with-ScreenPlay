# Automatización con screenplay

Proyecto de automatización de pruebas para una aplicación web bancaria utilizando el patrón **Screenplay**, con el objetivo de validar los principales flujos funcionales de la plataforma mediante pruebas automatizadas.

## Funcionalidades

- Automatización de escenarios de prueba.
- Validación de funcionalidades de la aplicación bancaria.
- Ejecución de pruebas automatizadas sobre la interfaz web.
- Verificación de resultados mediante aserciones.

## Tecnologías utilizadas

- Java
- Selenium WebDriver
- Serenity BDD
- Screenplay Pattern
- Gradle

## Estructura del proyecto

- **Features:** definición de los escenarios en lenguaje Gherkin.
- **Step Definitions:** implementación de los pasos definidos en los escenarios.
- **Tasks:** acciones que realiza el actor durante la prueba.
- **Interactions:** interacciones específicas con los elementos de la interfaz.
- **Questions:** validaciones y consultas sobre el estado de la aplicación.
- **User Interface (UI):** localizadores de los elementos de la página.
- **Models:** clases utilizadas para representar la información necesaria durante las pruebas.
